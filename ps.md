Problem Statement 1:
Build an AI Agent for Finance

This PS is inspired from the Pathway Problem Statement of
Inter-IIT Tech Meet 14.0.

Build an AI-powered Financial Agent using LangChain that can
optimize financial decisions and maximize savings or profits.
The system should integrate LLM reasoning, external financial
APIs/tools, memory, and agent-based workflows to provide
accurate, contextual, and actionable financial assistance in real
time.

Common Examples are:
AI stock portfolio advisor with risk analysis and market
sentiment tracking
Credit score improvement advisor with personalized
financial recommendations
Financial news summarization agent with impact analysis
on markets and portfolios

This Problem Statement has been deliberately kept open and
rewards novel ideas.

Scoring:
Solution Idea(15 %) - Clarity and Novelty of financial use-case,
objectives, and user needs

Agent Architecture (30 %) - Effective use of LangChain agents,
chains, tools, memory, and workflows, and integration with
APIs, databases, market data, or external tools

Reasoning Quality (35 %) - Quality and accuracy of financial
analysis, reasoning, and recommendations

Code Implementation (20 %) - Code quality, modularity,
scalability, and engineering practices
